# Imagens autorizadas

Este diretório deve receber somente imagens cujo uso na landing page tenha autorização explícita do titular dos direitos.

## Fluxo obrigatório

1. Solicite autorização escrita para cada foto do perfil Instagram `@rodrigodamacantor` antes de baixar ou publicar.
2. Registre a autorização fora do repositório se ela contiver dados pessoais ou informações privadas.
3. Salve apenas as imagens aprovadas neste diretório.
4. Otimize as imagens para WebP ou AVIF antes de substituir os arquivos usados pela página.
5. Mantenha textos `alt` descritivos no HTML, por exemplo: `Rodrigo Dama Cantor em apresentação ao vivo`.

## Arquivos esperados pela landing page

- `rodrigo-dama-cantor-ao-vivo.webp`: foto final otimizada para navegadores modernos.
- `rodrigo-dama-cantor-ao-vivo.svg`: arte temporária local, mantida como fallback até que a foto autorizada seja fornecida.
